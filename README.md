# Webb Ventures Homebrew tap

```bash
brew tap webb-ventures/tap
brew trust webb-ventures/tap
brew install --cask mergepond
```

Homebrew asks you to trust a tap before it installs from it; this one only holds Webb Ventures apps.

[Mergepond](https://mergepond.dev) is a Git client for the Mac. It updates itself, so `brew upgrade` leaves it alone.

The cask here is updated with each Mergepond release.
